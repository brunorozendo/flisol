Conceito fundamental

MVP = Mínimo Produto Viável

✅ É um MVP

  • Resolve 1 problema real
  • Tem usuários reais usando
  • Gera aprendizado mensurável
  • Pode ser feito em semanas

❌ Não é um MVP

  • Feature completa demais
  • Perfeito antes de lançar
  • Sem feedback de usuário
  • Sem métricas de sucesso

Mindset

Errar rápido. Aprender. Iterar.

BUILD

Construa o mínimo para testar a hipótese

Horas ou dias — não meses. Imperfeito é ok.

MEASURE

Meça com dados reais

Não com opiniões ou achismos. Métricas definem sucesso.

LEARN

Aprenda e decida

Pivota ou persiste — mas com base em evidência.

🤖 Ansible

Deploy automatizado como código

04

Infrastructure as Code

O que é Ansible?

  • Automatiza tarefas em servidores via SSH — sem instalar agente no host
  • Configuração em YAML legível por humanos
  • Idempotente — rode 10 vezes, o resultado é sempre o mesmo
  • Um playbook = deploy completo, do zero ao ar

❌ Sem Ansible

ssh → apt install → git clone → docker run → reza para não dar erro da próxima vez

✅ Com Ansible

ansible-playbook deploy.yml → pronto. Idêntico em qualquer servidor.

Código

Playbook de deploy

deploy.yml 
---
- name: Deploy app no homelab
  hosts: homelab
  become: yes

  tasks:
    - name: Instalar Docker
      apt:
        name: docker.io
        state: present

    - name: Subir container da aplicação
      docker_container:
        name: minha-app
        image: brunorozendo/minha-app:latest
        state: started
        ports:
          - "8080:8080"
        restart_policy: always

Por que usar

Ansible no homelab MVP

PKG

Reproduzível

Novo servidor? 1 comando e está igual. Sem "funciona na minha máquina".

GIT

Versionado no Git

Histórico de todas as mudanças de infra. Code review de infraestrutura!

RUN

Deploy em segundos

Novo release = ansible-playbook deploy.yml. Sem SSH manual.

UP

Escala para cloud depois

Mesmos playbooks funcionam na AWS/GCP quando o negócio crescer.

Tunnel

05

Exposição de serviço

Seu serviço na internet
SEM IP fixo

  • Conexão de saída do seu servidor para Cloudflare — nenhuma porta aberta no roteador
  • Usuários acessam via domínio normal com HTTPS automático (certificado incluso)
  • Gratuito no plano Free da Cloudflare
  • Latência baixa — CDN global da Cloudflare entrega o conteúdo
  • Proteção contra DDoS embutida

Antes: IP fixo no provedor = R$ 50+/mês. Agora: gratuito com Cloudflare

Comandos

Subindo o tunnel

bash 
# 1. Instalar cloudflared
curl -L https://pkgs.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare.gpg
sudo apt install cloudflared

# 2. Autenticar (abre browser)
cloudflared tunnel login

# 3. Criar o tunnel
cloudflared tunnel create meu-homelab

# 4. Criar rota DNS (aponta domínio para o tunnel)
cloudflared tunnel route dns meu-homelab app.meudominio.com.br

# 5. Rodar (aponta para app local)
cloudflared tunnel run --url http://localhost:8080 meu-homelab
